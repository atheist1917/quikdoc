Раздел описывает порядок запуска Рабочего места QUIK на ОС Astra Linux.

## **10.1 Подготовка к работе**


- Операционная система Astra Linux версии 1.7.4.

 - Рабочее место QUIK версии 11.4.0 или выше.

 - Подключенные репозитории пакетов Astra Linux.

 - WINE из репозитория Astra Linux.

## **10.2 Установка Рабочего места QUIK**


**1.** Перед началом работы установите программу WINE для ОС Astra Linux следующей

командой:

```
    sudo apt install wine

```

С подробной информацией по установке WINE можно ознакомиться по ссылке:

<u>https://wiki.astralinux.ru/pages/viewpage.action?pageId=27362502</u>


**2.** Установите пакет wine-gecko:

```
    sudo apt install wine-gecko

```

**3.** Для проверки наличия необходимых для работы программы локалей выполните команду:

```
    locale -a

```

Если результат выполнения команды не содержит строки ru_RU.utf8, выполните

следующую последовательность команд:

```
    #!/bin/sh

    echo ru_RU.UTF-8 UTF-8 | sudo tee -a /etc/locale.gen

```

```
## **10.3 Запуск Рабочего места QUIK в ОС Astra Linux**

```

**1.** Подготовьте дистрибутив Рабочего места QUIK (полный комплект файлов) и скопируйте

директорию с дистрибутивом на компьютер с ОС Astra Linux.


**2.** Если для авторизации на сервере используются файлы ключей, то в файле qrypto.cfg

путь к ключам должен быть указан следующим образом:

```
    secring=.\secring.txk

    pubring=.\pubring.txk

```

Файлы ключей secring.txk и pubring.txk должны быть расположены в директории

с Рабочим местом QUIK.


**3.** Запустите Рабочее место QUIK путем выполнения файла start_info.sh из дистрибутива

Рабочего места QUIK. Перед первым запуском этого файла добавьте права на

выполнение файла, для этого:


   - Перейдите в директорию с Рабочим местом QUIK – используется команда
cd <путь к директории QUIK>, например:

```
       cd /home/user/quikfront

```

   - Добавьте права на выполнение файла start_info.sh:

```
       sudo chmod +x start_info.sh

```

**4.** После выполнения указанных действий запустите Рабочее место QUIK, выполнив файл

start_info.sh.
